# SQLAlchemy Playground

## 📌 Цель

Изолированная среда для изучения SQLAlchemy:

- написание запросов
- понимание ORM
- отладка SQL
- изучение N+1

---

## ⚙️ Стек

- SQLAlchemy 2.0
- SQLite (in-memory)
- AsyncSession

---

## 🔍 Особенности

- echo=True → отображение SQL
- минимальная структура
- быстрый запуск без Docker

---

## 🧠 Основной фокус

- select / join
- relationship
- eager loading
- фильтрация
- агрегации

---

## 🚀 Как использовать

```bash
python app/main.py
```

---

## 📌 Примечание

Это не production-проект.
Это лаборатория для обучения ORM.
